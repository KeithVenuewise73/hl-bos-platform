# HL-BTI Consulting Intelligence Framework

**Product Creation Order #3** — the Herman Legacy Business Transformation Methodology, as deterministic software. The consulting brain behind every Herman Legacy engagement and every future product (HSCS, VisibilityAI, TransportationAI, SalonAI, FleetHuddle, HomeHuddle, …).

**Code:** `packages/bti-engine/src/consulting/` (in the canonical shared engine). **Entry point:** `generateConsultingReport(assessment)`.

## What it does

Turns a scored assessment into a full consulting package: 12-part evidence-traced findings (with FACT / INFERENCE / OPINION on every claim), a prioritized 4-bucket transformation roadmap, Herman Legacy solution mapping, an evidence-gated financial view, a board-ready executive narrative, and a CEO review package — all deterministic.

## Headlines

- **Deterministic consulting, not generative speculation:** scoring, prioritization, roadmaps, recommendation structure, root cause, solution mapping and confidence are pure functions with 13 tests. AI is reserved for prose polish and may never state a fact.
- **Evidence or nothing:** every recommendation traces to a verified rating; the financial engine says "Additional financial information required" rather than inventing ROI; the narrative marks empty sections instead of fabricating them.
- **Reuse-first:** a module inside the one canonical engine — no new schema, app, or platform service.
- **Proven with real output:** HSCS (49/100, 23 findings, full blueprint) and Venuewise (47/100, 11 findings, analysis-only) case studies are generated by the engine, not written by hand.
