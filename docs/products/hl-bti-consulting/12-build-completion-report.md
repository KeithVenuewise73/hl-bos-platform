## The two case studies (real, deterministic output)

- **HSCS** — a full Executive Business Transformation Blueprint from an **illustrative sample** logistics assessment (clearly labelled). Result: Transformation Score **49/100**, **23 findings**, **11 recommended services**, claims **23 FACT / 46 INFERENCE / 23 OPINION**. Because labor hours + cost/hour were supplied, the financial view computes an illustrative automation-savings line; everything else says "additional information required."
- **Venuewise** — an **Internal Transformation Assessment, analysis-only**. Result: Transformation Score **47/100**, **11 findings**. The document states "No proposal, implementation, billing, or migration," and the financial view is fully gated (no figures supplied). Consistent with Checkpoint 8B and the analysis-only cap.

Both are regenerated by running the engine — they are not hand-written.

## Determinism & AI boundary

Deterministic: scoring, prioritization, roadmap placement, recommendation structure, root-cause selection, solution mapping, financial gating, confidence, and the narrative facts. AI: reserved for natural-language polish only; the shipped narrative is deterministic and never depends on a model to state a fact. The AI must never invent facts — the architecture makes that structurally impossible for the financial and narrative modules.

## Honesty guarantees (proven by tests)

- Never fabricates scores, ROI, savings, revenue, benchmarks, competitor data, or projections — missing evidence returns "Additional financial information required" with the exact next input needed.
- Every recommendation traces to a verified rating (+ any attached evidence); inference and opinion are labelled and never presented as fact.
- Findings are generated only for real weaknesses; strengths are not padded into findings.
- The CEO review flags thin or extreme evidence rather than hiding it.
