# ACO — Step 1: Full Evidence-Engine Inventory

Every discovery, intelligence, and analysis capability already present in HL-BOS, with location, functionality, reusability, and integration readiness. **The headline: the evidence repository and a collector registry already exist.** The correction is mostly connecting what is built — not building new engines.

Legend — Integration readiness: **🟢 ready** (exists + tested, connect as-is) · **🟡 partial** (exists, needs activation/adaptation) · **🔴 absent** (must be architected).

| Capability                 | Location                                | Functionality                                                                                                                                                             | Reuse                                                  | Ready |
| -------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ----- |

Every collector writes here. | **Reuse as-is** — this **is** the Evidence Repository. | 🟢    |
| **Collector registry**     | `discovery.collectors` (0020)           | A **catalog (rows, not enum)** of collectors with `kind`, `is_active`. ## Conclusion

**~80% of the evidence-driven platform already exists** — the evidence store, collector registry, website scanner, VisibilityAI, blueprint/proposal engines, AI fence, and the consulting brain (which already accepts evidence). The correction is four bridges (evidence→dimension map, rating-proposal engine, evidence-linked ratings, asset model) plus **connecting and surfacing** what is built. No engine is duplicated.
