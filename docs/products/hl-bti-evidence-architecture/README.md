## The one thing to remember

**You already have ~80% of an evidence-driven platform** — the evidence store, the collector registry, the website scanner, VisibilityAI, the AI fence, the approval gate, and a consulting brain that already accepts evidence. The correction is **three deterministic bridges** (evidence→dimension map, rating-proposal engine, asset model) plus **connecting and surfacing** what's built. Reuse tally: **13 reuse · 3 modify · 3 new**. No duplicate platform service. This is a correction, not a rebuild.
