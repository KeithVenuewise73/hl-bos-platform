## The honesty principle that shaped everything

**We do not have live scan data for these real businesses.** So the library refuses to invent
visibility, SEO, traffic, review, authority or lead numbers. Every baseline is classified:

- **MEASURED** — computed from real Factory data (transformation readiness, capability reuse,
  commercialization readiness). **9 measured** across the three.
- **ESTIMATED** — a derived proxy, clearly labeled (marketing readiness). **3 estimated.**
- **UNKNOWN** — external metrics that require a live VisibilityAI scan that has **not been run**
  (the edge runtime is gated). **30 unknown**, each with a `null` value and the reason.

`noFabricatedMetrics` is asserted `true`: every non-unknown baseline cites a computed/derived
source; every unknown is `null`. **Expected outcomes are labeled TARGETS, never measured results.**
